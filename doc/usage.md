# BGM Finder 使用ガイド

## できること

- 現在Premiere Proで開いているプロジェクトのビンから、音源ファイルを検索して一覧表示します。
- 音源ごとにタグを追加・編集し、タグのAND条件で絞り込みます。
- タグはプロジェクトをまたいで、音源のファイル名に紐付けて保持します。
- 選択した音源をパネル内でプレビュー再生します。

## 起動とプロジェクトの読み込み

1. UXP Developer Toolに`manifest.json`を読み込み、Premiere Proで「BGM Finder」パネルを開きます。
2. Premiere Proで対象プロジェクトを開きます。パネル起動時に開いているプロジェクトの音源が読み込まれます。
3. 別のプロジェクトに切り替えたときや、プロジェクトに素材を追加したときは「プロジェクトを再読み込み」を押してください。

対象の拡張子はMP3、WAV、M4A、AAC、AIFF、FLAC、OGGです。プロジェクトのビン内にある素材を読み込みます。タイムラインに配置されているかどうかは問いません。動画ファイルやシーケンスは音源一覧に含めません。

## タグ付けと検索

1. 一覧からタグを付けたい音源を見つけます。
2. 音源カードのタグ欄に、タグをカンマまたはスペース区切りで入力します。
3. 「タグを保存」を押します。
4. 検索欄にタグを入力します。複数のタグを空白で区切ると、すべてのタグを持つ音源だけを表示します。

タグの大文字・小文字は区別しません。カンマまたはスペースで区切った入力は個別のタグとして扱われ、同じタグを重複して保存しません。

## プロジェクトをまたぐタグ情報

プラグインのデータフォルダーにある`library.json`へ、ファイル名とタグの組み合わせを保存します。音源本体やプロジェクトごとのパスは保存しません。プロジェクトを切り替えても、同じファイル名の音源には保存済みのタグが表示されます。

タグの識別子はファイル名（拡張子を含む）で、大文字・小文字を区別しません。そのため、別の場所にある同名ファイルは同じタグを共有します。別々に管理する必要がある音源には、異なるファイル名を付けてください。

データベース形式について、SQLiteのようなファイルDB自体は一般的に利用できますが、このプラグインのUXP実行環境には組み込みSQLite APIがありません。SQLiteを使うには別途対応ランタイムや依存パッケージが必要です。現在は、追加ランタイムなしで読み書きできるJSONファイルを小規模なタグカタログとして使用しています。

## プレビュー

音源カードの「プレビュー」を押すと再生します。ファイルが移動・削除された場合や、Premiere Pro/OSからファイルへのアクセスが許可されない場合は再生できません。その場合はファイルの場所やアクセス権を確認してください。

## 保存データの移行

以前のバージョンで登録した音源ライブラリがある場合、起動時に登録済みの音源名とタグを新しいファイル名ベースの形式へ移行します。旧バージョンの保存内容は移行後にタグカタログとして保持され、対象音源は現在開いているプロジェクトから読み込みます。
